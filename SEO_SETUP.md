# Checklist SEO technique — Pradice Services Nettoyage

## Google Search Console

1. Propriété de type **Domaine** déjà vérifiée pour `pradiceservicesnettoyage.fr` (DNS).
2. Soumettre `https://pradiceservicesnettoyage.fr/sitemap.xml` dans Sitemaps.
3. Utiliser **Inspection de l'URL** pour chaque nouvelle page créée (ex: `/entreprise-nettoyage-tours/`) et cliquer sur **"Demander une indexation"**.
4. Vérifier régulièrement (1x/semaine au début) :
   - **Pages** → repérer les pages "Non indexées" et comprendre pourquoi
   - **Performances** → quelles requêtes amènent des clics, quelle position moyenne
   - **Expérience** → Core Web Vitals (LCP, CLS, INP) en rouge/orange à corriger en priorité
5. À chaque nouvelle page statique créée (services, zones, blog), répéter les étapes 2-3.

## Après chaque nouvelle page créée

1. Vérifier que le `title`, la meta description, le H1 et le canonical sont uniques
2. Vérifier le JSON-LD avec l'outil officiel : https://search.google.com/test/rich-results
3. Ajouter l'URL au `sitemap.xml`
4. Ajouter un lien interne vers la page depuis au moins une page existante
5. Soumettre l'URL dans Search Console (étape 3 ci-dessus)
